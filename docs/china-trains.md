# 中国列车：按时刻表估算的位置

这是 Rail Globe 的中国列车图层，不是一个替换原站的“中国专用网站”。代码沿用仓库的 PolyForm Noncommercial 1.0.0 许可；原版权和 Required Notice 保留在根目录 LICENSE。列车数据的独立许可和处理来源见 `data/trains/README.md` 和同目录 CC BY 4.0 许可副本。

## 使用

运行原来的 `python scripts/serve.py`，打开本地网站，进入中国页面，再点“列车”。保留国家列表、其他国家数据、原来的路线/线路/图层功能和语言选择。原来的路线页仍为中国的默认页。

第一次打开中国“列车”页才读取 `data/trains/index.json` 并按需读取路径分片。切到其他国家或返回国家列表后，隐藏列车图层和角标，停止镜头跟随及每秒计算；已取得的数据保留在当前页面内，不会因切换反复下载。新的面板支持中英文，源数据里的车站名称不杜撰翻译。原生 app 暂不增加列车入口，继续使用它的既有页面协议。

列车图层支持车次/停靠站搜索、G/D/C/其他筛选、当前视野、停站表、定位/全程路径/跟随、选择北京时间。选中非在途行程时，只定位相应端点，不伪造在途位置。

## 数据性质和覆盖

**动态图标是按时刻表和路线距离推算的位置，不是 GPS/北斗/列控系统的真实位置。** 不包含实际停运、改线或实际晚点修正，不能作为乘车或行车依据。

随本次贡献保留了用户原型里的社区快照 `gtfs-20261012-065400`，不是本次重新下载的最新运营数据。快照内有 11,736 条中国范围行程记录，6,117 条具有通过编译器质量筛选的路径。81 条时序异常记录保留其审计信息，但运行引擎不将其作为可显示的有效行程；不能把所有记录数当作某时刻的列车数。数据说明中的日期区间只是总包日期范围，每一车次仍严格按自己列出的开行日判断，过期后不默认每天运行。

没有路径或路径质量检查失败时不生成站间直线来冒充轨道。上游 GTFS 几何经过简化和投影，不能保证与原地图每一条股道重合。当前中国范围筛选针对该快照已知的境外停站，不能视为对任意未来跨境数据都完备的国界校验。

详情的 RailGo 正晚点是可选的、用户手动点击的外部查询，不在开站/切页时批量请求。单次结果缓存五分钟，连续不同车次查询至少间隔十五秒。显示查询时间，返回的预测与实况状态分别标注；查询结果不自动平移地图位置。外部服务超时、CORS、接口变化或无数据时，铁路地图和静态时刻表仍独立工作。没有嵌入登录密钥或站点专用认证 token。

## 原项目中的文件

`src/app.html` 只增加列车页入口、一个空面板、样式/模块引用、地图就绪与页面状态通知，以及点击命中保护。保留原站的国家配置和界面。MapLibre 的 PMTiles 嵌套协议 URL 不再二次归一化，瓦片档案地址按文档基址生成绝对 URL，支持 GitHub Pages 的项目子目录。

`src/trains.mjs` 负责界面和地图，`train-core.mjs` 负责纯计算，`train-data.mjs` 负责带超时的 JSON 请求，`train-i18n.mjs` 和 `train-panel.mjs` 负责界面文字和面板。应用通过 `window.__rail.view()`、`rail:ready`、`rail:view`、`rail:language` 同步状态。调试用 `window.__chinaTrains` 是本页估算状态，不是真实列车位置 API。

`site.json`、原 `scripts/build.py`、其他国家文件、主 README、许可证及第三方库不改动。`index.html` 由原构建逻辑重新生成。贡献不包含独立站点部署设置、域名、下载包或账户访问策略。

## 构建与更新

查看已有快照不需要额外的 Python 包。Python 3.10+：

```bash
python scripts/build.py
python scripts/serve.py
```

浏览器打开 `http://localhost:8765`。不要直接双击 HTML 使用 `file://`，因为数据和模块需要 HTTP。

数据更新由维护者显式运行；不在页面首访时下载整个源 GTFS：

```bash
python scripts/build_trains.py --download
python scripts/build.py
```

或使用已取得的 GTFS：

```bash
python scripts/build_trains.py --gtfs /path/to/output_gtfs.zip --release RELEASE_TAG
python scripts/build.py
```

更新后复核 `data/trains/quality.json`，再提交数据和生成页面。算法参数与数据字段详见 `data/trains/README.md`。本贡献不安装任何自动爬取或定时更新任务。
